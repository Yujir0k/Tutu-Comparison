# Передача проекта другому агенту

## Цель

Продолжать разработку хакатонного прототипа «Туту Сравнение», визуально встроенного в публичный интерфейс Туту. Проект должен помогать сравнивать реальные поездки и отели на одном экране.

## Неприкосновенные продуктовые правила

1. Все предложения, цены, фотографии, отзывы и ссылки берутся из Tutu MCP. Не добавлять выдуманные карточки или скрытые mock-ответы.
2. Рекомендация работает на прозрачных правилах, без LLM. Расчёт должен быть одинаковым в выдаче и на экране сравнения.
3. Не принимать произвольный город: пользователь обязан выбрать подтверждённую подсказку геопоиска.
4. Фильтры применяются сразу к уже загруженным данным и снимаются повторным нажатием.
5. Сохранять визуальный язык Туту: тёмно-синий фон, фиолетовые действия, белые карточки, крупная типографика и мягкие скругления.
6. Не скрывать отсутствие данных. Если MCP не вернул поле, показать нейтральное отсутствие сведений, а не придумывать значение.
7. Ссылки «Выбрать» должны вести на максимально конкретное предложение Туту. Для авиа использовать `/api/checkout-link`.

## Текущее состояние

- Работают самолёты, поезда, автобусы и электрички в общей и раздельной выдаче.
- Есть сортировки, фильтры, пагинация и смешивание типов транспорта.
- Есть shortlist и сравнение до четырёх вариантов.
- Куратор детерминированно объясняет рекомендацию и основной компромисс.
- В пассажирах есть взрослые и до четырёх детей с возрастами 0–17 лет.
- Есть отдельный режим отелей с фотографиями, отзывами, условиями, сравнением и ссылкой на Туту.
- Сервер делает повторные попытки MCP и хранит последний успешный ответ в `.tutu-cache` 30 минут.
- При недоступности внешнего MCP интерфейс сохраняет форму и показывает кнопку повторного поиска.

## Главные файлы

- `src/App.tsx` — состояние приложения, запросы, выдача и сравнение.
- `src/styles.css` — вся визуальная система.
- `src/components/` — календарь, пассажиры, автодополнение и шапка.
- `src/types.ts` — контракты транспорта и отелей.
- `src/scoring.ts` и `server/agents.ts` — формулы рекомендаций.
- `server/index.ts` — локальные endpoints `/api/search`, `/api/hotels`, `/api/locations`, `/api/checkout-link`.
- `server/mcp.ts` — транспорт JSON-RPC до `https://mcp.tutu.ru/mcp`.

## Обязательная проверка после изменений

```bash
npm ci
npm run check
npm run build
npm run dev
```

Затем проверить в браузере минимум:

1. переключение «Все варианты» и отдельных типов транспорта;
2. выбор города только из подсказок;
3. календарь и добавление ребёнка с возрастом;
4. применение и снятие каждого фильтра без нового поиска;
5. «Показать ещё»;
6. добавление и удаление вариантов из сравнения;
7. режим отелей, фотографии и ссылку полного просмотра;
8. понятный экран ошибки при временно недоступном MCP.

## Внешнее ограничение

MCP может временно не устанавливать TLS-соединение из конкретной сети. Это не означает, что локальный API сломан. Сначала проверить `/api/health`, затем доступность `https://mcp.tutu.ru/mcp`. На другой сети внешний сервис может работать нормально.
