# Безопасность и устойчивость

## Модель угроз

Публичный браузер считается недоверенным. Tutu MCP считается внешним сервисом: его ответы могут быть медленными, неполными или неожиданно большими. Локальный файловый кэш считается недоверенным после чтения с диска.

## Реализованные меры

- строгая серверная валидация всех поисковых параметров и checkout reference;
- лимит JSON body 32 КБ;
- rate limit 120 API-запросов в минуту на IP;
- MCP timeout 20 секунд, две ограниченные попытки и лимит ответа 10 МБ;
- безопасные публичные ошибки без сетевых деталей и stack trace;
- CSP, запрет iframe, MIME sniffing, ограничение browser permissions, HSTS за HTTPS proxy;
- `x-powered-by` отключён;
- уникальный `X-Request-Id` и структурированный access log без тела запросов;
- атомарный bounded cache и graceful shutdown;
- неизвестный `/api/*` никогда не возвращает HTML приложения.

## Данные и секреты

Приложение не принимает платёжные данные и не хранит учётные записи. Бронирование происходит на Туту. Кэш содержит только общедоступные предложения поиска; каталог `.tutu-cache` исключён из Git и должен быть доступен на запись только пользователю процесса.

Секретов в репозитории нет. Если инфраструктура добавит токены, их следует передавать через environment/systemd credentials, не через `.env` в Git.

## Известные ограничения

- in-memory rate limit локален для процесса;
- CSP разрешает HTTPS-изображения, потому что фотографии приходят с CDN Туту;
- пользовательские аккаунты, платежи и PII не входят в область приложения.

Сообщения об уязвимостях следует передавать владельцу проекта приватно с шагами воспроизведения и оценкой воздействия.
